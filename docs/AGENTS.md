# Documentation Agent Instructions

Documentation in this directory is part of the implementation contract.

- Verify behavior against source before editing documentation.
- Use relative links so files work on GitHub and locally.
- Keep examples free of secrets and environment-specific credentials.
- Update `docs/README.md` when adding, renaming, or removing a document.
- Update the visualizer handbook when component ownership changes.
- Update device placement rules when catalog placement types, mounting heights, snapping, or rotations change.
- Update furniture layouts when room-type staging changes.
- Record current limitations clearly. Do not describe planned behavior as implemented.
- Prefer exact source paths, data keys, and coordinate rules over general descriptions.
